Goal N5.3 (Higher tier): Count combined choices using the product rule

Higher tier only. Foundation students can skip this part and do Q10 to Q12 on the next page instead.

Worked example (skip it if you're confident)

Ria has 3 shirts and 2 pairs of trousers. Draw one row per shirt; each row has 2 slots, one for each pair of trousers.

Equal rows: 2 + 2 + 2 = 6, which is 3 × 2 = 6 outfits. Adding 3 + 2 = 5 would count the clothes, not the outfits.

HT Q7 · Multiple choice

A café offers 4 starters and 3 mains. A meal is one starter and one main. How many different meals are there?

Hint 1

Draw one row for each starter. How many slots does each row have?

Hint 2

You have 4 equal rows of 3.

HT Q8 · Drag and drop into blanks (shown as multiple choice: pick the tiles for the blanks)

A meal deal is one sandwich, one drink and one snack. There are 3 sandwiches, 4 drinks and 2 snacks. Number of meal deals = ___ × ___ × ___ = ___. Tiles: 2, 3, 4, 9, 24. Which tiles fill the blanks?

Hint 1

Put the number of choices for each part of the deal into the first three blanks.

Hint 2

Work out 3 × 4 first, then multiply by 2.

HT Q9 · Numeric answer · no hints

A three-letter code uses the letters A, B, C, D, E and F. No letter can be used more than once. How many different codes are there?
