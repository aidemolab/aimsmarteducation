Foundation replacements for N5.3 (everyone)

Q7 · Numeric answer · Foundation replacement for Q5

A two-digit code uses the digits 1, 2 and 3. A digit may be used twice. List every code, holding the first digit fixed. How many codes are there?

Q8 · Open-ended (shown as a numeric answer, with an example explanation) · Foundation replacement for Q6

Find every way to pay exactly 20p using only 10p, 5p and 2p coins. You do not have to use every type of coin. Work systematically on paper by holding the number of 10p coins fixed, then type how many ways there are.

Example answer

Example (a fixed example, not marked by a computer): Two 10p. One 10p + two 5p. One 10p + five 2p. Four 5p. Two 5p + five 2p. Ten 2p. I held the number of 10p coins fixed at 2, 1 and 0, and inside each row I tried the 5p coins from most to fewest, so no way can be missed: 1 + 2 + 3 = 6.

Spacing: earlier N points inside N5 questions

Q9 · Numeric answer · Spacing: N4 (factors)

List all the factor pairs of 36 systematically, starting with 1 × 36. How many factors does 36 have? (Then check the example to see when you can stop searching.)

Example answer

Example (a fixed example, not marked by a computer): Stop after 6, because 6 × 6 = 36; any bigger first factor would repeat a pair already found.

Q10 · Ordering or sequencing (shown as multiple choice: pick the correct ordered list) · Spacing: N1 (ordering)

Using the digits 0, 3 and 7, each exactly once, list every three-digit number (a number cannot start with 0). Which list has every number, in ascending order?
