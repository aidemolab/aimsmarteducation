Checking a list: nothing missing, nothing twice

Goal: Check that a list, table or diagram is complete and counts no outcome twice.

In this video you'll learn one thing.

How to check a list, so that you can trust its total.

Here's a puzzle.

Four friends, Ali, Ben, Cara and Dev, choose two of them to be partners.

Sam lists every pair he can think of, and he gets twelve.

How many different partner pairs are there? Lock in one card.

Hold on to your guess.

A long list can still be wrong, so you need a check that catches mistakes before they cost you marks.

In N5.1 you listed outcomes by holding one choice fixed at a time.

Equal, full rows showed that nothing was missing.

Today we turn that idea into a check for any list.

First, we ask: does the order matter?

We ask it first, because it decides what counts as a repeat.

Ali with Ben is the same pair as Ben with Ali, so here the order does not matter.

Next, we draw a grid, with one row for the first person and one column for the second.

A grid shows every slot, so an empty or doubled slot is easy to see.

Four rows of four make sixteen slots.

We shade the diagonal, because Ali cannot be partners with Ali.

Sixteen take away four leaves twelve, which is Sam's twelve.

Pause point. Pause the video now. Where is the slot for Ben with Ali? Lock in one card, then press play.

Let's slow down here, because this is the key step.

Ben with Ali sits on the other side of the diagonal.

It is the same pair, so one of the two slots is a repeat.

Every pair appears twice like this, once on each side.

So we shade the lower half.

Twelve split into two equal halves leaves six pairs.

Read them from the grid: AB, AC, AD, then BC, BD, then CD.

Each row is one shorter, because each new person has already been paired with everyone above.

Three, plus two, plus one, also makes six.

Two ways of counting agree, so we can trust the answer.

Back to the puzzle: Sam counted every pair twice, so there are six pairs.

A café mixes two different flavours in one milkshake: banana, chocolate, mango and strawberry.

Mia's list is BC, BM, BS, CB, CM, MS and SM.

Let's check it.

Does the order matter? The flavours are mixed in one cup, so no.

Pause point. Pause the video now. We are going to rewrite each card with its letters in alphabetical order. Why does that help? Lock in one card, then press play.

It makes a swapped repeat look exactly like the original.

CB becomes BC, which matches the first card.

SM becomes MS, which matches the card before it.

So we cross out those two repeats, which leaves five.

Now, is every row full?

Banana pairs with the other three flavours: BC, BM and BS, so that row is full.

Chocolate has already met banana, so its row should be CM and CS.

CS is missing.

Mango only has strawberry left, so MS completes its row.

We add CS, so the correct list is BC, BM, BS, CM, CS and MS.

Three, plus two, plus one, makes six.

For a second count, a four-by-four grid has sixteen slots; take away four for the diagonal, then halve twelve to get six.

Both counts agree: six milkshakes.

You've learned to check that a list, table or diagram is complete and counts no outcome twice.

First decide whether the order matters.

Check that every row is full, so nothing is missing.

Remove swapped repeats, so nothing is counted twice.

Then count a second way, and make sure the totals agree.
