Goal N3.2: Use inverse operations to undo a calculation and check an answer

Worked example (skip it if you're confident)

Check that 84 ÷ 7 = 12. The inverse of ÷ 7 is × 7, so run it backwards: 12 × 7 = 84. We land back on 84, so the answer is right.

Q4 · Matching (shown as multiple choice: pick the list where every pair is right)

Which list matches each operation to the operation that undoes it?

Hint 1

An inverse brings you back to the pin you started on.

Hint 2

Adding and subtracting undo each other. Multiplying and dividing undo each other.

Q5 · Numeric answer

I think of a number. I multiply it by 4, then add 3. My answer is 31. What number did I think of?

Hint 1

Undo the steps in reverse order: the last step first.

Hint 2

The last step was + 3, so first work out 31 − 3.

Q6 · True or false with a reason · no hints

Jess works out −6 − 4 and gets −2. She checks by adding 4 to her answer. Is Jess's answer correct?
