Exam-style questions: N3 only, page 3

An open-ended number machine question. Original questions in the style of an AQA GCSE paper. Do them without a calculator. M marks are for a correct method, A marks for a correct answer after a correct method, B marks for a correct answer or statement on its own.

Q8(a) · Open-ended · [1 mark]

(a) The input is 7. Work out the output.

Here is a number machine: Input → × 6 → − 10 → ÷ 4 → Output

Mark scheme

B1 for 8.

Q8(b) · Open-ended · [2 marks]

(b) The output is 14. Work out the input.

Here is a number machine: Input → × 6 → − 10 → ÷ 4 → Output

Mark scheme

M1 for using inverse operations in reverse order, for example 14 × 4 = 56 then 56 + 10 = 66.

A1 for 11.

Q8(c) · Open-ended · [3 marks]

(c) Find an input that gives an output equal to the input. Type the input here, then explain on paper how you found it and show that it works.

Here is a number machine: Input → × 6 → − 10 → ÷ 4 → Output

Mark scheme

M1 for a correct method: trying inputs and comparing output with input (for example, input 3 gives 3 × 6 − 10 = 8, then 8 ÷ 4 = 2, which is too small), or any other valid reasoning.

M1 for a correct trial of 5 showing 30, 20 and 5, or for correct reasoning that leads to 5.

A1 for 5 with a check that the output is 5. Accept any clear method that is fully explained.

Example answer (fixed example, not marked by a computer): “Input 3 gives 2, which is too small. Input 5: 5 × 6 = 30, 30 − 10 = 20, 20 ÷ 4 = 5. The output is 5, the same as the input.”
