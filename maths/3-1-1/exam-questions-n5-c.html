Exam-style questions: N5 only

Original questions in the style of an AQA GCSE paper. Command words: list, write down, work out, show that, explain. M marks are for a correct method, A marks for a correct answer after a correct method, B marks for a correct answer or statement on its own.

Q7(a) · Numeric answer · [2 marks]

A lock code has two digits. Each digit is 1, 2, 3 or 4. Digits can repeat. (a) Work out how many different codes there are.

Mark scheme

M1 for a systematic list or for four rows of four.

A1 for 4 + 4 + 4 + 4 = 16.

Q7(b) · Open-ended (shown as multiple choice: pick the explanation that earns the mark) · [1 mark]

(b) Explain how you know that your answer includes every code once.

Mark scheme

B1 for an explanation that refers to holding one digit fixed, or to equal, full rows.

Q8 · Open-ended (shown as multiple choice: pick the method that earns the marks) · [3 marks]

Five students meet. Each student shakes hands once with every other student. Show that there are 10 handshakes. Explain your method clearly.

Mark scheme

M1 for a systematic method, such as holding one student fixed and listing their handshakes, or a table with the diagonal removed.

M1 for avoiding double counting, for example pairing only with later students, or halving an ordered count.

A1 for showing 10 with clear working, for example 4 + 3 + 2 + 1 = 10. Accept any correct systematic method.

Example answer

Example (a fixed example, not marked by a computer): Name the students A, B, C, D and E. Hold A fixed: AB, AC, AD, AE (4). Hold B fixed and pair only with later letters: BC, BD, BE (3). Then CD, CE (2), then DE (1). Total 4 + 3 + 2 + 1 = 10.
