Goal N5.2: Check that a list, table or diagram is complete and counts no outcome twice

Worked example (skip it if you're confident)

Leo lists pairs of two different fruits from apple (A), banana (B) and cherry (C), where order does not matter: AB, AC, BA, BC.

Rewrite each pair in alphabetical order: AB, AC, AB, BC. BA is a repeat of AB, so cross it out.

Row check: A pairs with B and C (2), then B pairs with C (1): 2 + 1 = 3 pairs: AB, AC, BC.

Second count: a 3 by 3 grid has 9 slots; remove the 3 on the diagonal to get 6; halve for repeats to get 3.

Q4 · True or false with a reason

Sam throws two coins, a 1p and a 2p. He lists: HH, HT, TH, TT, HT. He says, “My list has 5 outcomes, so there are 5 possible outcomes.” True or false? Choose the reason.

Hint 1

Hold the 1p coin fixed. How many outcomes should each row have?

Hint 2

Look for any outcome that appears more than once.

Q5 · Sort into groups (shown as multiple choice: pick the correct sorting)

In which situations does the order matter? (a) A two-digit door code. (b) Two friends chosen to share a desk. (c) First and second place in a race. (d) Two toppings on a pizza.

Hint 1

Swap the two items. Do you get something different?

Hint 2

A code 12 and a code 21 open different doors.

Q6 · Spot the error in a worked solution · no hints

Four people, A, B, C and D, each shake hands once with every other person. Ben writes: AB, AC, AD, BA, BC, BD, CA, CB, CD, DA, DB, DC. “So there are 12 handshakes.” What is Ben's error?
