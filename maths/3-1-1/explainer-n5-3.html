Counting choices without listing them all

Higher tier only. Foundation students can skip this part.

Goal: Count combined choices using the product rule.

In this video you'll learn one thing.

How to count outcomes without writing them all down.

Here's a puzzle.

A restaurant has four starters and three mains.

A meal is one starter and one main.

How many different meals are there? Lock in one card.

Hold on to your guess.

Listing works when there are only a few outcomes.

But a four-digit PIN has far too many to write down, so we need a way to count without listing.

In N5.1 you listed outcomes in rows, holding one choice fixed in each row.

Every row had the same length.

And from N2 you know that equal groups can be added or multiplied.

Three groups of two is two, plus two, plus two, which is three times two.

First, we draw one row for each starter, because every meal begins with exactly one starter.

Next, we give each row one slot for each main, because any main can follow any starter.

Every row has three slots, because the choice of main does not depend on the starter.

So we add equal rows: three, plus three, plus three, plus three, makes twelve.

Four equal rows of three is four times three: twelve meals.

Let's slow down here, because this is the key step.

Back to the puzzle.

If you locked in seven, you added four and three.

But seven counts the dishes on the menu, not the meals.

Each meal is a pair of dishes, so we count the cells inside the rectangle, not the labels round its edge.

This is the product rule.

If the first choice can be made in m ways, and for each of those the second can be made in n ways, there are m times n ways to make both.

The rule also works with more slots, and when a choice cannot be repeated.

Think of three-letter codes from A, B, C, D and E, with no letter used twice.

The first slot can use any of the five letters.

The second slot has four left, because one has been used.

Pause point. Pause the video now. Predict how many letters are left for the third slot. Lock in one card, then press play.

The third slot has three left, because two have been used.

Five times four is twenty, and twenty times three is sixty codes.

How many odd three-digit numbers can be made from the digits 1, 2, 3, 4 and 5, if no digit is used more than once?

A number is odd when its last digit is odd, so the units slot has a rule of its own.

Pause point. Pause the video now. Which slot should we fill first? Lock in one card, then press play.

We fill the units slot first, because it is the slot with the rule.

If we left it until last, the number of odd digits still free would depend on what we had already used.

Filling it first gives it a fixed number of choices.

The odd digits are 1, 3 and 5, so the units slot has three choices.

One digit is now used, so the hundreds slot has four choices.

Two digits are used, so the tens slot has three choices.

By the product rule, we multiply: four times three is twelve, and twelve times three is thirty-six.

Let's check.

Each of the three odd units digits leaves the same twelve ways to fill the other two slots, and three times twelve is thirty-six.

So there are thirty-six odd numbers.

You've learned to count combined choices using the product rule.

Find how many ways each choice can be made.

Fill any slot with a rule first.

Reduce the choices when an item cannot be used again.

Then multiply, because each choice splits every earlier outcome into equal rows.

Adding counts the options, not the combinations.
